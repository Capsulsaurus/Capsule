# Internationalization

## Rules

- No hardcoded user-facing strings. Every translatable string is a key in the canonical catalogs under `locales/` (ICU MessageFormat). Add the key there, not inline in app code. `mise run i18n-guard` scans the app sources for violations.
- After editing `locales/`, run `mise run i18n` to regenerate the per-platform files (Rust bundle, web JSON, Android `strings.xml`, iOS `.xcstrings`). Generated files are committed and carry a "do not edit by hand" banner; `mise run i18n-check` (part of `check-rust`) fails on drift. The generated outputs are `capsule-i18n/src/bundles/`, `capsule-i18n/src/generated.rs`, `capsule-web/src/i18n/messages/`, `capsule-android/src/main/res/values*/strings.xml`, `capsule-android/src/main/res/xml/locales_config.xml` and `capsule-swift/Generated/*.xcstrings`.
- App layout is logical (leading/trailing, start/end; never left/right), directional icons mirror, and text containers absorb expansion. `mise run i18n-guard` also refuses physical-direction layout in the web, Swift and Compose sources; a deliberate exception is a commented entry in `locales/i18n-guard-allowlist.txt`. See [i18n — Layout](../../capsule-docs/src/content/docs/design/i18n.md#layout).
- Keys use dotted namespaces (`area.subarea.name`). Server errors carry a stable `code` from the `error.*` namespace (referenced via `capsule_i18n::error_codes`); clients localize the code while the English detail message stays English.
- Catalog keys are namespaced by **surface, not by client**: a product concept present on more than one platform takes no platform prefix, because the generated Android and Apple catalogs are emitted from the same keys. Only genuinely platform-only chrome (a macOS menu bar) carries one.
- Language and region are separate settings in every app: language picks the catalog, region drives date, number and unit formatting. Both default from the OS.
- The CLI and TUI are English-only: their strings are inline English and the shared `error.*` codes render through the English catalog. The catalog rule above applies to the apps, the web client and the server.
