---
title: 시작하기
description: Capsule 사용을 시작하는 방법
audit: none
---

Capsule은 종단 간 암호화된 사진 및 미디어 라이브러리입니다. 아직 릴리스가 공개되지 않았으므로,
지금은 소스에서 빌드하고([](/development/local-development/)) `capsule` 명령줄을 사용합니다.
CLI로 이미 다음 작업을 할 수 있습니다.

- 로컬 암호화 라이브러리를 만들고 파일을 가져오기(Google 포토 내보내기
  포함, [](/guides/google-photos-migration/))
- 서버에 가입하고 로그인한 뒤, 라이브러리를 서버로 푸시하고 다시 동기화해 내려받기
- 공유 링크를 만들고 취소하기

자신의 서버를 직접 운영할 수 있습니다([](/guides/self-hosting/)). 공개 인스턴스를 원하신다면
[토론 #81](https://github.com/Capsulsaurus/Capsule/discussions/81)에 반응을 남겨 주세요.

모든 명령과 옵션은 CLI 레퍼런스([](/reference/cli/))에 있습니다.
