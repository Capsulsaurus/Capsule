Capsuleは、エンドツーエンドで暗号化された写真・メディアライブラリです。まだリリースは公開されていないため、現時点ではソースからビルドし（[](/development/local-development/)）、`capsule`コマンドラインを使います。CLIではすでに次のことができます。

- ローカルの暗号化ライブラリを作成し、Googleフォトのエクスポート（[](/guides/google-photos-migration/)）も含めてファイルを取り込む。
- サーバーに登録してサインインし、ライブラリをサーバーにプッシュして、手元に同期し直す。
- 共有リンクを作成・取り消す。

自分のサーバーを動かすこともできます（[](/guides/self-hosting/)）。公開インスタンスを希望する場合は、[ディスカッション #81](https://github.com/Capsulsaurus/Capsule/discussions/81)にリアクションしてください。

すべてのコマンドとオプションは、CLIリファレンス（[](/reference/cli/)）に掲載されています。
