Capsuleはボランティアによってオープンに開発・サポートされています。有償や非公開のサポート窓口はありません。質問、報告、アイデアはすべてプロジェクトのGitHubを通じて受け付けており、誰でも回答でき、その回答は次に同じ問題に出会う人の助けにもなります。唯一の例外は脆弱性で、これは非公開で報告します。

Capsuleはまだリリースされていません。現在動作するものと次に予定されているものは[ロードマップ](https://github.com/Capsulsaurus/Capsule/blob/master/ROADMAP.md)にあります。

<a id="before-you-ask"></a>

## 質問する前に

ほとんどの答えはすでに存在します。ここで1分かけるだけで、たいていはやり取りを1往復減らせます。

1. **ドキュメントを検索してください**。各ページ上部の検索ボックスを使い、[](/guides/troubleshooting/)を読んでください。よくある障害とログの集め方を説明しています。
2. **[オープンおよびクローズ済みのissue](https://github.com/Capsulsaurus/Capsule/issues?q=is%3Aissue)** と[Discussions](https://github.com/Capsulsaurus/Capsule/discussions)を検索してください。すでに誰かが報告している場合は、重複したものを新たに作るのではなく、👍のリアクションを付けるか、新しい情報があればコメントしてください。
3. **コマンドが受け付けるフラグを正確に確認してください**。[](/reference/cli/)に記載されています。

## 助けを求める

<CardGrid>
  <Card title="質問する" icon="comment">
    どうすればいい？これは想定どおりの動作？セットアップで困っている？そんなときは[Discussions › Q&A](https://github.com/Capsulsaurus/Capsule/discussions/categories/q-a)で質問してください。解決につながった返信を回答としてマークすると、次の人が見つけやすくなります。

  <Card title="脆弱性を報告する" icon="padlock">

<a id="what-to-expect"></a>

## 期待できること

- **ボランティアの時間で対応します**。質問には、コミュニティとメンテナーが時間の許す範囲で回答します。回答までの時間は保証されません。
- **情報の揃った報告から対応されます**。バージョン、再現手順、ログが揃ったバグ報告は、確認して修正できます。それらがない報告は、誰かが対応できるようになるまで返信を待つことになります。
- **1つのスレッドには1つのトピックを**。2つの問題は2つの報告に分けてください。そうすれば、それぞれを個別に追跡してクローズできます。
- **原則として公開されます**。脆弱性の報告を除き、すべての内容は公開されます。ログを貼り付ける前に、パスフレーズ、リカバリーシークレット、トークン、サーバーのアドレス、個人的なファイルパスを伏せてください。
