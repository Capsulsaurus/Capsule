---
title: 快速开始
description: 如何开始使用 Capsule
audit: none
---

Capsule 是一个端到端加密的照片和媒体库。目前尚未发布任何版本，因此现在需要从源代码构建（[](/development/local-development/)）并使用 `capsule` 命令行。借助 CLI，你已经可以：

- 创建本地加密照片库并向其中导入文件，包括 Google 相册导出（[](/guides/google-photos-migration/)）；
- 在服务器上注册并登录，将照片库推送到服务器，再将其同步回本地；
- 创建和撤销共享链接。

你可以运行自己的服务器（[](/guides/self-hosting/)）。如果希望有一个公共实例，请在[讨论 #81](https://github.com/Capsulsaurus/Capsule/discussions/81) 中留下表情回应。

所有命令和选项都列在 CLI 参考（[](/reference/cli/)）中。
