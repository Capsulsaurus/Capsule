Capsule — библиотека фотографий и медиафайлов со сквозным шифрованием. Ни одного выпуска ещё не
опубликовано, поэтому сегодня вы собираете проект из исходного кода
([](/development/local-development/)) и работаете через командную строку `capsule`. С помощью
CLI уже можно:

- создать локальную зашифрованную библиотеку и импортировать в неё файлы, в том числе
  экспорт из Google Photos ([](/guides/google-photos-migration/));
- зарегистрироваться и войти на сервер, отправить на него свою библиотеку и синхронизировать её
  обратно;
- создавать и отзывать ссылки для общего доступа.

Можно запустить собственный сервер ([](/guides/self-hosting/)). Чтобы попросить публичный
экземпляр, отреагируйте на [обсуждение #81](https://github.com/Capsulsaurus/Capsule/discussions/81).

Все команды и параметры описаны в справочнике CLI ([](/reference/cli/)).
