Capsule 由志工以公開方式打造與支援。專案沒有付費或私人的支援管道：所有問題、回報與想法都透過專案的 GitHub 提出，任何人都可以回答，而這些回答也能幫助下一個人。安全性弱點是唯一的例外，需要私下回報。

Capsule 尚未發布任何版本；目前可用的功能與接下來的計畫請見[路線圖](https://github.com/Capsulsaurus/Capsule/blob/master/ROADMAP.md)。

<a id="before-you-ask"></a>

## 提問之前

大多數問題都已經有答案。在這裡花上一分鐘，通常就能省去一次往返溝通。

1. **搜尋文件**：使用每個頁面頂端的搜尋框，並閱讀 [](/guides/troubleshooting/)，其中涵蓋常見的故障以及如何收集日誌。
2. **搜尋[未關閉與已關閉的 issue](https://github.com/Capsulsaurus/Capsule/issues?q=is%3Aissue)** 以及[討論區](https://github.com/Capsulsaurus/Capsule/discussions)。如果已經有人回報過，請加上 👍 表情回應，或發表包含新資訊的留言，而不要重複提出。
3. **查閱指令接受的確切旗標**：請見 [](/reference/cli/)。

## 取得協助

<CardGrid>

  <Card title="回報安全性弱點" icon="padlock">

<a id="what-to-expect"></a>

## 您可以期待什麼

- **志工的時間**。問題由社群與維護者在有空時回答，沒有保證的回應時間。
- **完整的回報優先處理**。附有版本、重現步驟與日誌的錯誤回報可以被確認並修正。缺少這些資訊的回報需要先等待補充回覆，之後才有人能著手處理。
- **一個主題一則討論**。兩個問題應分成兩份回報，以便各自追蹤與關閉。
- **預設公開**。除了安全性弱點回報之外，所有內容都是公開的，因此在貼上日誌之前，請刪去密碼短語、復原憑證、權杖、伺服器位址與個人檔案路徑。
