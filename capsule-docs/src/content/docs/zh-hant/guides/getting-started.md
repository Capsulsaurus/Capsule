---
title: 開始使用
description: 如何開始使用 Capsule
audit: none
---

Capsule 是一個端對端加密的相片與媒體庫。目前尚未發布任何版本，因此現階段需要從原始碼建置（[](/development/local-development/)），並使用 `capsule` 命令列。透過 CLI，您已經可以：

- 建立本機加密相片庫並將檔案匯入其中，包括 Google 相簿匯出檔（[](/guides/google-photos-migration/)）；
- 在伺服器上註冊並登入、將相片庫推送到伺服器，再將其同步回本機；
- 建立與撤銷分享連結。

您可以執行自己的伺服器（[](/guides/self-hosting/)）。如果希望有公開的執行個體，請在[討論 #81](https://github.com/Capsulsaurus/Capsule/discussions/81) 中留下表情回應。

所有指令與選項都列在 CLI 參考（[](/reference/cli/)）中。
