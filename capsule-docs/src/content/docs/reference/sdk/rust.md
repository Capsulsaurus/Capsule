`capsule-sdk` is the sanctioned network path for every Capsule client: the upload protocol, sync
and download, and the authentication flows. The CLI and TUI link it directly, and the
[](/reference/sdk/swift/) and [](/reference/sdk/kotlin/) bindings are its `ffi` feature,
generated by uniffi. The crate is not published to crates.io, so its item-level reference is the
[workspace rustdoc](/rustdoc/capsule_sdk/), rendered from master;
`cargo doc --workspace --no-deps --open` builds it locally. This page is the map to read it with.

## What is generated and what is not

The typed REST client, `capsule_sdk::rest`, is generated at build time by spargen from the
committed `capsule-server/openapi.json`: one `async` method per operation, with typed models and
typed errors. It is documented once, as the [](/reference/api/) reference, not again here.

What the crate writes by hand is orchestration over those generated calls, never a second parser.

- `upload` drives the resumable upload state machine, the one protocol too stateful for
  request-and-response generation. Its contract is [](/design/transfer/upload/).
- `sync` drives the cursor and anti-rewind state machine over the generated `GET /v1/sync`
  operation. Its contract is [](/design/sync/).
- `directory`, `upgrade` and the receipt fetch in `verify` are the `application/cbor` operations
  the generator cannot lower yet.

## Authentication

A caller authenticates once and then makes typed calls, never handling a raw token.
`AuthenticatedClient`, in the `client` module, wraps the generated `rest::Client` and composes it
with the `auth` session store. The model is [](/design/authentication/).

- Before a request leaves, it refreshes a token that is close to expiry.
- When the server refuses a token anyway (a revocation, or two clocks that disagree), it refreshes
  once and replays the request once.
- A `401` that refuses a credential, such as a wrong password or second-factor code, is returned
  unchanged.
- Concurrent refreshes coalesce into one.

## The FFI feature

`--features ffi` compiles the uniffi-annotated surface the native apps drive:

- `FfiCapsuleClient` and `FfiSession` for the networked flows;
- `FfiWorkspace` for the local workspace verbs;
- the hardware-signer and key-agreement traits a platform implements.

The feature is off by default, so the workspace, the CLI and the server never compile it.
`mise run gen-bindings` builds the feature and generates both languages from the compiled library.
