O Capsule é uma biblioteca de fotos e mídia com criptografia de ponta a ponta. Nenhuma versão foi
lançada ainda, então hoje você compila a partir do código-fonte ([](/development/local-development/))
e usa a linha de comando `capsule`. Com a CLI você já pode:

- criar uma biblioteca local criptografada e importar arquivos para ela, incluindo uma exportação
  do Google Fotos ([](/guides/google-photos-migration/));
- se cadastrar e entrar em um servidor, enviar sua biblioteca para ele e sincronizá-la de volta;
- criar e revogar links de compartilhamento.

Você pode rodar o seu próprio servidor ([](/guides/self-hosting/)). Para ter uma instância pública,
reaja à [discussão nº 81](https://github.com/Capsulsaurus/Capsule/discussions/81).

Todos os comandos e opções estão na referência da CLI ([](/reference/cli/)).
