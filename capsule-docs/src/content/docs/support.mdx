Capsule is built and supported in the open by volunteers. There is no paid or private support
channel: every question, report and idea goes through the project's GitHub, where anyone can answer
it and the answer helps the next person. A vulnerability is the one exception, and it is reported
privately.

Capsule has not had a release yet; what works today and what is next is in the
[roadmap](https://github.com/Capsulsaurus/Capsule/blob/master/ROADMAP.md).

## Before you ask

Most answers already exist. A minute here usually saves a round trip.

1. **Search the docs** with the search box at the top of every page, and read
   [](/guides/troubleshooting/), which covers the common failures and how to collect logs.
2. **Search the [open and closed issues](https://github.com/Capsulsaurus/Capsule/issues?q=is%3Aissue)**
   and the [discussions](https://github.com/Capsulsaurus/Capsule/discussions). If someone has
   already reported it, add a 👍 reaction, or a comment with new information, rather than opening
   a duplicate.
3. **Check the exact flags a command takes** in [](/reference/cli/).

## Get help

<CardGrid>
  <Card title="Ask a question" icon="comment">
    How do I…? Is this expected? Help setting something up? Ask in
    [Discussions › Q&A](https://github.com/Capsulsaurus/Capsule/discussions/categories/q-a). Mark the
    reply that solved it as the answer, so the next person finds it.
  </Card>
  <Card title="Report a bug" icon="warning">
    Something broke or behaves differently from the docs? Open a
    [bug report](https://github.com/Capsulsaurus/Capsule/issues/new?template=bug_report.yml). The
    form asks for the version, platform, steps to reproduce and logs: a report with all of
    them can be triaged without a back-and-forth.
  </Card>
  <Card title="Suggest a feature" icon="star">
    Share ideas in
    [Discussions › Ideas](https://github.com/Capsulsaurus/Capsule/discussions/categories/ideas),
    where others can upvote and refine them. Maintainers turn an idea into an issue once it is
    accepted, and the issue is where the work is tracked.
  </Card>
  <Card title="Report a vulnerability" icon="padlock">
    **Never in a public issue.** Report it privately through a
    [GitHub security advisory](https://github.com/Capsulsaurus/Capsule/security/advisories/new).
    The [security policy](https://github.com/Capsulsaurus/Capsule/security/policy) says which
    versions receive fixes.
  </Card>
</CardGrid>

## What to expect

- **Volunteer time.** Questions are answered by the community and the maintainers as time allows.
  There is no guaranteed response time.
- **Complete reports move first.** A bug report with a version, the steps to reproduce and logs
  can be confirmed and fixed. One without them waits for a reply before anyone can act on it.
- **One topic per thread.** Two problems belong in two reports, so each can be tracked and closed
  on its own.
- **Public by default.** Everything except a vulnerability report is public, so redact passphrases,
  recovery secrets, tokens, server addresses and personal file paths before you paste a log.
