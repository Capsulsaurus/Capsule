Capsule ist eine Ende-zu-Ende-verschlüsselte Foto- und Medienbibliothek. Bisher wurde noch kein
Release veröffentlicht, daher bauen Sie Capsule heute aus dem Quellcode
([](/development/local-development/)) und verwenden die Kommandozeile `capsule`. Mit der CLI
können Sie bereits:

- eine lokale verschlüsselte Bibliothek anlegen und Dateien hineinimportieren, auch einen
  Google-Fotos-Export ([](/guides/google-photos-migration/));
- sich bei einem Server registrieren und anmelden, Ihre Bibliothek dorthin übertragen und sie
  wieder herunter synchronisieren;
- Freigabelinks erstellen und widerrufen.

Sie können Ihren eigenen Server betreiben ([](/guides/self-hosting/)). Wenn Sie sich eine
öffentliche Instanz wünschen, reagieren Sie auf
[Diskussion #81](https://github.com/Capsulsaurus/Capsule/discussions/81).

Jeder Befehl und jede Option steht in der CLI-Referenz ([](/reference/cli/)).
