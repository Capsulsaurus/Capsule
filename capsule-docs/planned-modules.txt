# Modules the design specifies and the tree does not have yet.
#
# Format, tab-separated:
#   <module path>	<why it does not exist yet, and the issue that lands it>
#
# Keyed on the path alone: a module that does not exist does not exist in every
# doc that names it. `mise run check-docs-truth` fails on an entry whose module
# has since been built, and on one no doc names any more, so this list cannot
# quietly outlive either condition.
#
# This is deliberately the *only* way a design doc may name a module that is not
# there. Everything here is a commitment nobody has met yet — read it as the
# module-layer answer to "what has been designed and not built?"

capsule-core::ml::pipeline	Pipeline contracts `(task, pipeline_version)`: preprocessing, ONNX I/O signature, postprocessing, output class. The compiled-in `ml::Registry` inventory stands in until then. Contract: design/ai.md § Pipelines and Versioning. Tracked by #1276.
capsule-core::ml::weights	Typed records of the signed, append-only weight registry, its anti-rollback check and per-lineage release selection. Contract: design/ai.md § Weight Registry. Tracked by #1276.
capsule-sdk::ml	On-demand weight fetch, the hash-pinned URL override, the known-answer readiness gate and per-tier download. No real runner exists yet to fetch for. Contract: design/ai.md § Distribution and Readiness. Tracked by #1276.
capsule-core::media::video	The video half of the media module: first-frame still extraction and the H.264 baseline preview transcode. The still half now exists (`capsule-core::media` on rawshift-image, pinned to a commit of rawshift's git master until rawshift publishes a stable release: keep bumping that pin); this does not, because `rawshift-video` is still an unimplemented placeholder at that commit (visualcommons/rawshift#39, #74) and video comes only from Rawshift, never from a codec Capsule links itself (design/licensing.md § The video transcoder seam). Contract: design/thumbnails.md § Video Previews. Tracked by #907.
capsule-core::search	The pure half of local search: query grammar parse/print, compilation to the smart-album predicate tree. Contract: design/search.md. Lands with the search-grammar issue filed from the architecture-overhaul PR.
capsule-library::search	The stateful half of local search: SQLite FTS5 trigram tables, the memory-mapped fst suggester and recent searches over the catalog. Contract: design/search.md. Lands with the search-index issue filed from the architecture-overhaul PR.
capsule-core::places	Pure places maths: Web Mercator cell ids, the cluster pyramid arithmetic and datum handling. Contract: design/places.md. Lands with the location-index issue filed from the architecture-overhaul PR (follows #987/#988).
capsule-library::places	The location index, cluster pyramid and per-cell place-name cache in the catalog. Contract: design/places.md. Lands with the location-index issue filed from the architecture-overhaul PR (follows #987/#988).
capsule-library::export	Plaintext export: plan/run/resume, ZIP (zip writer) and tar outputs, sidecars and the checksums manifest, behind FFI and wasm sinks. Contract: design/export.md. Lands with the export-core issue filed from the architecture-overhaul PR.
capsule-library::memories	On-device memory generators (On This Day, trips, people, birthdays) over the catalog. Contract: design/memories.md. Lands with #1290.
