# i18n-guard allowlist (slices S-I1, S-I5)
#
# The `xtask i18n-guard` gate fails the build when it finds a hardcoded, user-facing
# string literal in the web (JSX), SwiftUI, Compose, or CLI (Rust) surfaces that is not
# a catalog key. This file lists the exceptions so the gate stays at zero false
# positives.
#
# Format: one exception per line, `<repo-relative-path>\t<exact captured string>`
# (TAB separated). `#` comments and blank lines are ignored. Prefer migrating a
# string to a `locales/en.json` key over allowlisting it — only allowlist text that
# is genuinely not translatable (brand names shown verbatim, sample data, etc.).
#
# ## The CLI block below is DEBT, not exemption
#
# Slice `S-I5` widened the guard to `capsule-cli/src/**` — a binary that prints prose to
# a terminal and had never been scanned — and migrated the `capsule import` arm onto the
# `cli.import.*` namespace. The guard immediately found 124 more literals (107 distinct
# strings) across three other command surfaces. They are listed here rather than hidden
# by a narrower rule,
# because an allowlist entry is a visible debt and a narrowed rule is an invisible one:
# every line below is a string a user reads in English regardless of their locale, and
# deleting a line is the definition of done for the follow-up slice that migrates it.
#
# Do NOT add a CLI line here to make a new command pass. New CLI output goes straight
# into `locales/en.json` under `cli.<command>.*`; the mechanism already exists
# (`capsule_cli::i18n::keys`) and the import arm is the worked example.
#
# Keep this list SHORT and justify each entry with a comment above it.

# `PHAssetResource` exposes no public byte count, so its size is read by KVC.
# `forKey:` is a Key-Value Coding key here, not a catalog key — the guard matches
# the `…Key:` argument label and cannot tell the two apart.
capsule-swift/Modules/ImagePipeline/Sources/ViewerMediaLoader.swift	fileSize

# `AssetInfoFormatting.hdrName(_:)` names an HDR encoding "as its owner spells it" (its own
# doc comment). "Dolby Vision" is a Dolby trademark, spelled the same in every locale — the
# allowlist's stated category, and the same reason the sibling arms "HDR10" and "HLG" never
# tripped the guard. Surfaced when `S-I7` widened `swift-computed-property` to `func`
# members; the alternative would be a `locales/` key whose thirteen translations are all
# the identical trademark.
capsule-swift/Modules/FeatureViewer/Sources/Info/AssetInfoFormatting.swift	Dolby Vision
